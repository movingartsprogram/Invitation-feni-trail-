# Feni Trail invitation page

"An Invitation — The Feni Trail": the invitation sent to guests for The Feni Trail,
17–18 October 2026, Dudhsagar Plantation ("A day and a night on the farm").
Served by GitHub Pages from `main`. This repo is public, so never put private guest
details in it.

## Ground rules

- The owner chose to leave this page as it is. Only change it when explicitly asked.
- `index.html` on `main` is the latest version. If someone uploads an `index.html`,
  it may be older: compare it with `main` and merge changes in. Never replace the
  repo's file with the upload.
- Do not bring back anything listed under "Decided and done" below.
- One page, no build step. Media are separate files next to it, never inline base64:
  `farm-map.jpg` (farm map) and `ouro.mp4` (Ouro film). Never delete or rename a file
  the live page uses in the same change that stops using it.

## Decided and done (do not undo)

- The Ouro film and the farm map are served as separate files (they used to be
  embedded as base64, which made the page huge).
- Personal invitations: adding `?to=Name` to the link puts the guest's name on the
  page (max 40 characters).
- Contribution shown on the page: ₹3,000 per guest.
